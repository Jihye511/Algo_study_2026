# 🚀 제출 방법

### 1. 이번 주 브랜치 생성

브랜치명 규칙

```
week01/이름
```

예시

```
week01/jihye
```

---

### 2. 프로그래머스에서 문제 풀이

이번 주 지정된 4문제를 프로그래머스에서 풉니다.

---

### 3. GitHub에 코드 업로드

본인 브랜치에서 `week01/이름` 폴더를 생성한 후 풀이 코드를 업로드합니다.

예시

```
week01/
└── jihye/
    ├── 01_두_수의_합.java
    ├── 02_폰켓몬.java
    ├── 03_올바른_괄호.java
    └── 04_기능개발.java
```

> 4문제를 모두 **같은 브랜치**에 업로드합니다.

---

### 4. Pull Request 생성

4문제를 모두 업로드한 후 **Pull Request를 1개만 생성**합니다.

#### PR 제목

```
[Week01] 이지혜
```

PR 내용은 자동으로 생성되는 **PR Template**을 작성합니다.

---

### 6. Merge

리뷰가 완료되면 스터디장이 `main` 브랜치로 Merge합니다.
